iTranslator Text Area

This demo uses the same standalone widget build as the sample page. It works directly from your computer; no server or installation is needed.

Another iTranslator Text Area

How to use it

  1. Widgets start compact. Use the open-in-full icon below Copy to reveal the controls.
  2. Start in iTrans mode and type ASCII ITRANS, such as raama, R, or RR.
  3. Press Ctrl+S or Ctrl+I to toggle between iTrans and English.
  4. Press Ctrl+R to toggle between Roman/IAST and iTrans; press Ctrl+O to toggle between English and iTrans.
  5. Press Ctrl+E or Escape for English mode, which leaves input unchanged.
  6. Use Ctrl+Z or Ctrl+U to undo; use Ctrl+Shift+Z or Ctrl+Shift+U to redo.
  7. In Settings, enable the global iTrans disable seq. option to use = (or your own three-character sequence) for English text until the end of the current line.
  8. Use the mode-tab settings to choose language, font, auto-expand, and optional page-wide settings.
  9. Enter a font size from 14–48 in the small px field and press Enter (or leave the field) to apply it.
  10. Use the microphone to record up to five minutes. In the waveform editor you can preview a selection, delete or silence it, insert silence, undo/redo five audio edits, reset, save, and download.
  11. Saved audio remains in this browser for 30 days. The Play control below Copy becomes available after saving and is marked if the associated text later changes.
  12. Use Save to export this widget's text, language, mode, font, size, and saved audio as one .itarea.zip file. Use Open to restore it; the widget warns before replacing existing content.

Use the widget in another page

Directly from the public repository

For a page with internet access, use the pinned release below. Keep the version the same in both URLs and change it only when you intentionally upgrade.

<link rel="stylesheet"
      href="https://cdn.jsdelivr.net/gh/rbairigit/itarea@v1.2.0/dist/itarea.css">

<script src="https://cdn.jsdelivr.net/gh/rbairigit/itarea@v1.2.0/dist/itarea-standalone.js"></script>

<i-translator-textarea label="Sanskrit text" audio-id="lesson-1"></i-translator-textarea>

From a local folder

Copy the complete dist/ folder, including fonts/, beside your page. This works from a file:// URL.

<link rel="stylesheet" href="./dist/itarea.css">
<script src="./dist/itarea-standalone.js"></script>

<i-translator-textarea label="Sanskrit text" audio-id="lesson-1"></i-translator-textarea>

Audio recording and storage

Assign each reusable widget a unique, stable audio-id. Audio saved in the editor is associated with that ID and retained in this browser's IndexedDB storage for 30 days. It is not uploaded or included in the text value.

Audio can be retrieved through widget.audioBlob and widget.audioDurationMs. The widget also emits an audiochange event after audio is saved or deleted. Clearing browser site data, moving a local page, changing its URL, or using another browser profile can make a saved recording unavailable.

Microphone permission: recording from a local file:// page works in tested Chrome/macOS configurations. Other browsers may require the page to run from localhost or HTTPS.

Portable save and open files

Reveal the compact controls and use Save to create a portable .itarea.zip document. It stores the Unicode text, current mode, selected language, font, font size, and any audio saved in the recorder. The file contains a versioned manifest.json plus an optional normalized audio.wav.

Use Open to restore the document into any iTranslator Text Area. The archive is validated first, and a confirmation appears before nonempty text or recorded audio is overwritten. If its font is unavailable in the receiving package, the widget uses the System default font and reports that substitution.

Keep the original file: this first implementation uses an uncompressed ZIP container so the standalone widget needs no ZIP library. Do not unpack and recompress the archive before reopening it in the widget.

Configuration and mappings

The standalone build embeds its configuration. To change mappings, default languages, or font options, edit config/itrans-config.json and run npm run build again.

Supported targets: Sanskrit, Telugu, Kannada, Tamil, Malayalam, and Roman (IAST). Sanskrit uses Devanagari script. The configuration file is the complete, editable list of ITRANS aliases and script mappings.
Useful built-in mappings

R → ऋ, RR → ॠ, S → ष, L → ळ, OM/AUM → ॐ, | → ।, and || → ॥.

Digits are converted to the selected script. The settings control lets each widget choose its own language, font, and size, or apply those choices globally.
