iTranslator Text Area

This demo uses the same standalone widget build as the sample page. It works directly from your computer; no server or installation is needed.

Another iTranslator Text Area

How to use it

  1. Widgets start compact. Use the open-in-full icon below Copy to reveal the controls.
  2. Start in iTrans mode and type ASCII ITRANS, such as raama, R, or RR.
  3. Press Ctrl+S or Ctrl+I to toggle between iTrans and English.
  4. Press Ctrl+R to toggle between Roman/IAST and iTrans; press Ctrl+O to toggle between English and iTrans.
  5. Press Ctrl+E or Escape for English mode, which leaves input unchanged.
  6. Use Ctrl+Z or Ctrl+U to undo; use Ctrl+Shift+Z or Ctrl+Shift+U to redo.
  7. In Settings, enable the global iTrans disable seq. option to use = (or your own three-character sequence) for English text until the end of the current line.
  8. Use the Expand icon beside Duplicate to toggle automatic height expansion. Use the mode-tab settings to choose language and optional page-wide settings.
  9. Use the Tags icon to add queryable name/value metadata. Every widget includes the required type=rich-text-audio tag, which cannot be changed or deleted.
  10. Use the font selector beside the mode buttons to change selected text or the text typed next at the caret.
  11. Use the responsive formatting group to format selected text: bold, italic, underline, lists, 36 preset colors or a custom color, font size, font weight, line spacing, four-character indentation, alignment, links, and remove formatting. With only a caret, font, size, color, and weight apply to what you type next. The controls wrap into additional rows when the widget is narrow.
  12. The default style is 24px Demi. ITF Devanagari is used when installed; otherwise the bundled Noto Sans Devanagari is used automatically.
  13. Use the microphone to record up to five minutes. In the waveform editor you can preview a selection, delete or silence it, insert silence, undo/redo five audio edits, reset, save, and download.
  14. Saved audio remains available for this page session only. Refreshing clears it unless it has been exported with Save. The Play control below Copy becomes available after saving and is marked if the associated text later changes.
  15. A red dot on Save means text, audio, language, mode, font, or size has changed since the last export. Use New to add an empty widget below, or Duplicate to copy text and settings; audio is copied only when enabled in Settings.
  16. Enable Resize width in Settings to show the right-edge width handle.
  17. Use Save to export this widget's plain text, formatted HTML, language, mode, font, size, and saved audio as one .itarea.zip file. Use Open to restore it; the widget warns before replacing existing content.

Use the widget in another page

Directly from the public repository

For a page with internet access, use the pinned release below. Keep the version the same in both URLs and change it only when you intentionally upgrade.

<link rel="stylesheet"
      href="https://cdn.jsdelivr.net/gh/rbairigit/itarea@v1.3.0/dist/itarea.css">

<script src="https://cdn.jsdelivr.net/gh/rbairigit/itarea@v1.3.0/dist/itarea-standalone.js"></script>

<i-translator-textarea label="Sanskrit text" audio-id="lesson-1"></i-translator-textarea>

From a local folder

Copy the complete dist/ folder, including fonts/, beside your page. This works from a file:// URL.

<link rel="stylesheet" href="./dist/itarea.css">
<script src="./dist/itarea-standalone.js"></script>

<i-translator-textarea label="Sanskrit text" audio-id="lesson-1"></i-translator-textarea>

Audio recording and saving

Audio saved in the editor is available only for the current page session and is cleared by a refresh. It is not uploaded. Use Save to include audio with the text in an .itarea.zip document, or Download for a separate audio file.

Audio can be retrieved through widget.audioBlob and widget.audioDurationMs. The widget also emits an audiochange event after audio is saved or deleted.

Microphone permission: recording from a local file:// page works in tested Chrome/macOS configurations. Other browsers may require the page to run from localhost or HTTPS.

Saving, New, Duplicate, and width

Text is not persisted automatically. A red dot on Save means its portable document is not current; the Save tooltip reads not saved. After a successful save it disappears and the tooltip reads Saved.

The New and Duplicate buttons appear with the expanded controls. New inherits the current language, font, and text size but begins empty. Duplicate also copies the text, mode, and auto-expand setting. It intentionally leaves audio behind unless Include audio when duplicating is enabled in Settings. New and duplicate widgets have a trash control; the original widget cannot be deleted.

Tags are available to the containing page through widget.tags and widget.getTag(name). Use widget.setTag(name, value) or widget.removeTag(name) to update them in JavaScript, and listen for tagschange to react to user changes. Duplicate copies the tags; New starts with only type=rich-text-audio. Save/Open preserves the complete tag list.

Enable Resize width in Settings to display a right-edge drag handle. The widget cannot be widened beyond its parent container.

Portable save and open files

Reveal the compact controls and use Save to create a portable .itarea.zip document. It stores plain Unicode text, sanitized formatted HTML, current mode, selected language, font, font size, tags, and any audio saved in the recorder. The file contains a versioned manifest.json plus an optional normalized audio.wav. Older plain-text widget documents remain openable.

For page integrations, widget.value remains the plain-text API. Read or assign widget.htmlValue for sanitized formatted HTML. Copy places both formats on the clipboard when supported.

Use widget.getState() to retrieve one snapshot containing tags, plain and rich text, content and audio update times, default font information, audio data, resizing options, identifiers, language, mode, widget version, and dirty. A dirty value of true means the widget has unsaved changes; modifying the returned snapshot does not modify the widget.

Use Open to restore the document into any iTranslator Text Area. The archive is validated first, and a confirmation appears before nonempty text or recorded audio is overwritten. If its font is unavailable in the receiving package, the widget uses the System default font and reports that substitution.

Confirmations, warnings, filename and link entry, and errors use dialogs matching the widget. Press Escape, select ×, or select outside a dialog to cancel it; focus then returns to the control that opened it.

Keep the original file: this first implementation uses an uncompressed ZIP container so the standalone widget needs no ZIP library. Do not unpack and recompress the archive before reopening it in the widget.

Configuration and mappings

The standalone build embeds its configuration. To change mappings, default languages, or font options, edit config/itrans-config.json and run npm run build again.

Supported targets: Sanskrit, Telugu, Kannada, Tamil, Malayalam, and Roman (IAST). Sanskrit uses Devanagari script. The configuration file is the complete, editable list of ITRANS aliases and script mappings.

In Telugu, Kannada, Tamil, and Malayalam, lowercase e/o produce the short vowels and uppercase E/O produce the long vowels. This works for independent vowels and after consonants. The newer Ra mapping produces Tamil ற and Malayalam റ. Sanskrit keeps its established lowercase e/o behavior.

Customizing the widget theme

Load your own stylesheet after itarea.css and override the public CSS variables. Apply them to :root for every widget, to a parent container for a group, or directly to one named widget.

.blue-editors {
  --itarea-accent: #2457a7;
  --itarea-accent-hover: #183f7d;
  --itarea-accent-soft: #e8f0ff;
  --itarea-border-color: #aebbd0;
  --itarea-radius: 12px;
}

The theme layer covers interface colors, mode backgrounds, surfaces, borders, dialogs, shadows, audio waveforms, typography, spacing, control dimensions, and corner radii. See THEMING.md for the complete variable reference.

Useful built-in mappings

R → ऋ, RR → ॠ, S → ष, L → ळ, OM/AUM → ॐ, | → ।, and || → ॥.

Digits are converted to the selected script. Settings controls the widget language and default size; the formatting-row Font control applies fonts to selections or subsequent typing.
