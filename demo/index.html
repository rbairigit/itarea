iTranslator Text Area

This standalone demo works directly from your computer - no server or installation is needed.

How to use it

  1. Start in iTrans mode and type ASCII ITRANS text, such as raama, R, or RR.
  2. The ITRANS text is replaced in the same input. For example, raama becomes राम, R becomes ऋ, and RR becomes ॠ.
  3. Press Ctrl+S or Ctrl+I to select iTrans mode.
  4. Press Ctrl+R for Roman mode, which replaces ITRANS input with IAST (for example, kRtaj~naH becomes kṛtajñaḥ).
  5. Press Ctrl+E, Ctrl+O, or Escape for English mode. The input turns light grey and its contents remain unchanged.
Custom mappings: Edit config/itrans-config.json when using the reusable widget in an application. This standalone page intentionally embeds the starter mapping so it can be opened with a double-click.

Using the widget in another page

Run npm run build in the project folder, then copy the complete dist/ folder into your website. There are two supported ways to use it.

Use directly from the public repository

For a page with internet access, load the pinned standalone release from the public repository. Keep the same version in both URLs; change it only when you intentionally upgrade.

<link rel="stylesheet"
      href="https://cdn.jsdelivr.net/gh/rbairigit/itarea@v1.0.1/dist/itarea.css">

<script src="https://cdn.jsdelivr.net/gh/rbairigit/itarea@v1.0.1/dist/itarea-standalone.js"></script>

<i-translator-textarea label="Sanskrit text"></i-translator-textarea>

Hosted page or local web server

For a site served over HTTP(S), use the editable JSON configuration. For example, if the folder is copied to /assets/itarea/:

<link rel="stylesheet" href="/assets/itarea/itarea.css">

<div id="translator"></div>

<script type="module">
  import {
    configureITranslator,
    setITranslatorTarget
  } from '/assets/itarea/itarea.js';

  const config = await fetch('/assets/itarea/itrans-config.json')
    .then(response => response.json());

  configureITranslator(config);
  setITranslatorTarget('telugu'); // Optional; Sanskrit is the default.
  document.querySelector('#translator').innerHTML =
    '<i-translator-textarea label="Sanskrit text"></i-translator-textarea>';
</script>
Important: Create the widget only after configureITranslator(config). Browsers block JSON loading from a file:// page, so this option needs a local web server or hosted site.

Page opened directly from disk

For a simple file:// page, use the standalone build. Its configuration is embedded when you run npm run build:

<link rel="stylesheet" href="../dist/itarea.css">
<script src="../dist/itarea-standalone.js"></script>

<i-translator-textarea label="Sanskrit text"></i-translator-textarea>

Configuration and custom mappings

The reusable widget reads config/itrans-config.json. Add normal aliases to aliases. If an alias is a vowel, also add its combining sign to vowelMarks, so it works after consonants. Add the matching IAST spelling to iastTokens when it should work in Roman mode too.

{
  "aliases": { "R": "ऋ", "RR": "ॠ" },
  "vowelMarks": { "R": "ृ", "RR": "ॄ" },
  "iastTokens": { "R": "ṛ", "RR": "ṝ" }
}

For example, R becomes ऋ by itself, while kR becomes कृ because R has a combining vowel sign. Reload the widget after changing the JSON file.
